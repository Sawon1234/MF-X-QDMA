# MF-X-QDMA — multifractal quantile detrending moving-average cross-correlation analysis

Code and data accompanying

> S. Pratiher, *Multifractal quantile detrending moving-average cross-correlation analysis*, submitted to Physical Review E (2026).

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/<YOUR-GITHUB-USERNAME>/MFQDMA-PaperII/blob/main/MFQDMA_PaperII.ipynb)

**One notebook reproduces the whole paper.** Open `MFQDMA_PaperII.ipynb` in Google Colab with the badge above and choose *Runtime → Run all*. The notebook clones this repository, installs the requirements, and regenerates all **9 figures** and all **7 data tables** (Tables I–VII). It then checks the figures against the manuscript versions and offers the outputs as a zip file. This takes a few minutes.

By default the figures and tables are built from the stored numerical results in `results/`. Switch on the `RECOMPUTE` flags in Part 1 of the notebook to regenerate those results from scratch. All seeds are fixed, and recomputing reproduces the stored results exactly. Rough run times on a free Colab runtime (about 1.5 h in total):

| Flag | Results | Paper items | Time |
|---|---|---|---|
| `offset` | `cross_offset.json` | Table I, Fig. 2 | ~3 min |
| `bench_B` | `cross_bench.json` (B1–B4) | Tables II–IV, Figs. 3–5 | ~20 min |
| `bench_C` | `cross_bench.json` (C1–C3) | Table V, Fig. 6 | ~1 h |
| `finance_AB` | `cross_finance.json` (AB) | Table VI, Fig. 7 | ~5 min |
| `finance_GH` | `cross_finance.json` (G, H) | Table VII, Figs. 8, 9 | ~10 min |

Figure 1 is computed directly in the notebook.

## Contents

```

mfqdma/                Python package
  methods.py             univariate MFDFA, MFDMA, MFQDMA (shared with Paper I)
  methods_cross.py       MF-X-DFA, MF-X-DMA, MF-X-QDMA in 1D and 2D; detrended coefficients rho(n), rho_q(n);
                         exact binomial / 2D cascade-pair cross exponents
  generators.py          binomial and 2D cascade pairs, bivariate fGn, two-component ARFIMA, contamination
  experiments_paperII.py one function per results file (called by the notebook's Part 1)
  cross_bench.py, cross_finance.py   experiment code
  figures_paperII.py     one function per figure
  table_rows_paperII.py  the LaTeX rows of every table;  tables_paperII.py  the same as DataFrames
  rdata_reader.py        pure-data reader of R .rda files (qrmdata); no R needed
  finance.py, paths.py, plotting.py, stats_tools.py, theory_2d.py, verify.py
results/               stored numerical results read by the figures and tables
figures/               the figures exactly as in the submitted manuscript (reference for the check)
requirements.txt       numpy, scipy, matplotlib, pandas, scikit-learn, pillow
set_github_user.py     fills in your GitHub user name in the README and the notebook
```

Created when the notebook runs: `figures_out/` (PDF + PNG of every figure), `tables_out/` (LaTeX rows of every table), `data/qrmdata/` (clone of the price data), and, when the benchmarks are recomputed, `datasets/` + `MANIFEST.json` (the BFGN and ARFIMA pairs).

## Data

* **Synthetic data** are generated by `mfqdma/generators.py` with fixed seeds.
* **Financial data:** daily prices, the VIX and U.S. zero-coupon yields from the CRAN package *qrmdata* (M. Hofert, K. Hornik and A. J. McNeil), cloned automatically from <https://github.com/cran/qrmdata> and read by `mfqdma/rdata_reader.py`. This parser reads data only and executes nothing from the files.

## Running locally

```bash
pip install -r requirements.txt
jupyter notebook MFQDMA_PaperII.ipynb
```

The estimator can also be used directly, e.g.

```python
from mfqdma.methods_cross import mfx1d
r = mfx1d(x, y, q_list, scales, method='qdma', theta=0.0, lams=((0.5, 0.5),))
r[(0.5, 0.5)]['hq'], r[(0.5, 0.5)]['rho_n']     # h_xy(q) and rho(n)
```
